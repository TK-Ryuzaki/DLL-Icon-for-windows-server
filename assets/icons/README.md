# Icônes source

Ajoutez ici les fichiers `.ico` personnalisés à intégrer dans la DLL. Utilisez des noms stables et uniques (par exemple `server.ico`, `workstation.ico`). CMake génère un identifiant de ressource numérique à partir de l’ordre alphabétique des noms ; consultez `build/generated/resource_ids.h` après compilation.
